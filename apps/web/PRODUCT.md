# Product

## Register

product

## Platform

web

## Users

**Mike Villar** — solo user. CEO of Growth Rocket (digital marketing agency, Metro Manila). Active randonneur and cyclist. Manages his business, clients, health, and personal life from one interface. Uses TARS on desktop primarily, with iOS PWA installed for mobile. Expects a system that knows him and operates without explanation.

## Product Purpose

TARS is Mike's personal AI operating system — a single interface that consolidates chat, tasks, meetings, calendar, contacts, feed, second brain, agent jobs, artifacts, and cron automation. Every screen serves one job: make Mike faster and sharper at running his life and company. Success means zero friction between a thought and an action, and zero loss of context between sessions.

## Positioning

The AI operating system that feels like a precision instrument, not an assistant.

## Brand Personality

Direct, precise, machine-efficient. Inspired by TARS from Interstellar: no padding, no filler, gets things done. Humor setting: 75% — dry and earned, never performative. The interface reads like a readout from a very capable machine that respects your intelligence.

## Anti-references

- **Generic AI chat UIs** (ChatGPT, Claude.ai): white backgrounds, blue message bubbles, minimal chrome, conversation-as-product. TARS is an operating system, not a chatbot.
- **Mainstream AI aesthetic** broadly: the 2024-2026 wave of warm-cream/sand backgrounds, rounded bubbly components, gradient text, and "friendly" copy. If it looks like an AI product, it's wrong.
- No corporate SaaS sameness — no purple/indigo accents, no crowded card grids, no hero metrics template.

## Design Principles

1. **Instrument over assistant.** Every element should read like part of a precision readout. The UI is chrome around information, not a personality in itself.
2. **Depth by surface, not decoration.** Hairline borders, the canvas→surface→surface-2 stack, and ambient light do all the work. No shadows, no glassmorphism by default, no gradient text.
3. **Mono as the machine voice.** JetBrains Mono carries the system layer — labels, badges, timestamps, model chips, metadata. Inter carries the human layer — prose, titles, conversation. Never swap them.
4. **Accent as signal, not style.** Moss is the single accent: active state, focus ring, primary action, live indicator. Amber and rose are status-only (warning, error). No decorative color.
5. **Silence is speed.** Interactions should feel instant and settled. Animation is earned and purposeful; no entrance choreography for its own sake.

## Accessibility & Inclusion

WCAG 2.1 AA. Body text ≥4.5:1 contrast against background. `prefers-reduced-motion` respected — animated elements (TTS pill, ambient gradients, thinking indicators) fall back to instant transitions or static states.
